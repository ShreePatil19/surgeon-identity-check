Surgeon identity check

The same surgeon listed twice, or a profile showing the wrong English name, undercuts a "verified surgeon" badge. This page runs a deterministic resolver over a snapshot of the public Gangnam Beauty Guide doctor directory and shows every decision with its evidence.

Safe to merge

Same Hangul name, identical review count and identical rating. Two independent signals agree.

Needs a human

Same Hangul name, but the stats are missing or differ. Korean names collide often, so these could be two different people.

English name does not spell the Hangul

Checked by romanising the Hangul (Unicode syllable arithmetic, Revised Romanization) and comparing a variant-tolerant consonant key, syllable by syllable.

How it decides

  1. Block on Hangul, not English. Romanisation is many-to-one (Gang/Kang, Hyeong/Hyung, U/Woo); Hangul is what Korean sources publish. Whitespace and Unicode form are normalised first.
  2. Auto-merge only on two agreeing signals (review count and rating). A wrong merge would attach one surgeon's reviews and credentials to another person, which is worse than a duplicate.
  3. Everything else goes to a human, with the reason attached.
  4. No language model in the loop. Identity decisions in a medical directory have to be explainable and reversible.

Limits

  • Hangul name is a blocking key, not a unique key. The real key is name plus clinic plus medical licence number; the directory list does not expose clinic, so it is not used here.
  • Personal spellings can trip the name check (for example "Da-Arm" for 다앎). That is why flags go to review rather than being auto-corrected.
  • Two-syllable surnames (남궁, 선우) are not handled.
